# Research Quality Controls

Before presenting research, verify:
- [ ] Source quality: Is the source reputable and unbiased?
- [ ] Recency: When was the information published? Is it still valid?
- [ ] Consistency: Do credible sources agree on key facts?
- [ ] Fact vs inference: Is each statement directly supported by evidence?
- [ ] Missing information: What remains unknown?
- [ ] Decision relevance: Does this information directly affect the decision?
- [ ] Actionability: What should happen as a result?
